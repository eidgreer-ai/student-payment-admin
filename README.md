# 📚 تطبيق إدارة الطلاب والمدفوعات

تطبيق متكامل لإدارة المجموعات الدراسية وتتبع المدفوعات الشهرية للطلاب. يوفر واجهة سهلة وسريعة بدعم كامل للغة العربية مع جداول شهرية تفاعلية وتقارير مالية شاملة.

## ✨ المميزات الرئيسية

### 🔐 نظام الأمان
- نظام تسجيل دخول آمن بكلمة مرور
- تغيير كلمة المرور من الإعدادات
- حماية البيانات المحلية

### 🎓 إدارة المجموعات والطلاب
- إنشاء وتعديل وحذف المجموعات
- إضافة الطلاب للمجموعات
- تحديد قيمة الاشتراك الشهري لكل مجموعة
- إدارة بيانات الطلاب بسهولة

### 📊 جداول المدفوعات الشهرية
- جدول شهري تفاعلي (أغسطس - يونيو)
- تمييز الشهر الحالي تلقائياً
- ألوان ديناميكية:
  - 🟢 أخضر: المبلغ مسدد
  - 🔴 أحمر: المبلغ غير مسدد
- تحديث فوري عند تسجيل المدفوعات

### 📈 الجرد والحسابات
- إجمالي التحصيل الشهري والسنوي
- قائمة الطلاب غير المسددين
- رسوم بيانية توضيحية
- تصفية حسب المجموعة أو الشهر
- البحث عن طالب بالاسم

### ⚙️ الإعدادات المتقدمة
- تغيير كلمة المرور
- نسخ احتياطي للبيانات (JSON)
- استعادة النسخة الاحتياطية
- تبديل الوضع الليلي والفاتح
- إدارة الأدوار والصلاحيات

### 📱 التصميم والواجهة
- واجهة عصرية وجميلة
- دعم كامل للغة العربية (RTL)
- تصميم Responsive يعمل على الموبايل والكمبيوتر
- أيقونات واضحة وجميلة
- انتقالات ناعمة بين الصفحات

## 🛠️ التقنيات المستخدمة

### Frontend
- **React 19** - مكتبة واجهات المستخدم
- **Tailwind CSS 4** - تصميم الواجهة
- **TypeScript** - لغة البرمجة
- **Vite** - أداة البناء

### Backend
- **Express.js** - خادم الويب
- **tRPC** - نظام الاتصال بين الواجهة والخادم
- **MySQL/TiDB** - قاعدة البيانات

### Mobile
- **Capacitor** - تحويل التطبيق إلى تطبيق موبايل
- **Android** - نظام التشغيل المستهدف

### أدوات إضافية
- **Drizzle ORM** - إدارة قاعدة البيانات
- **Recharts** - رسوم بيانية
- **shadcn/ui** - مكونات واجهة جاهزة

## 📦 المتطلبات

- Node.js 18+
- pnpm 10+
- Java 17+ (لبناء APK)
- Android SDK (لبناء APK)

## 🚀 البدء السريع

### 1. تثبيت المتطلبات
```bash
cd student_payment_admin
pnpm install
```

### 2. تشغيل التطبيق محلياً
```bash
pnpm dev
```

### 3. فتح المتصفح
```
http://localhost:3000
```

### 4. تسجيل الدخول
- كلمة المرور الافتراضية: `admin123`

## 📱 بناء APK للأندرويد

### باستخدام GitHub Actions (الطريقة الموصى بها)
1. ادفع التغييرات إلى GitHub
2. اذهب إلى تبويب "Actions"
3. انتظر انتهاء البناء
4. حمّل ملف APK من الـ Artifacts

### بناء محلي
```bash
# بناء الويب
pnpm build

# مزامنة Capacitor
npx cap sync android

# بناء APK
cd android
./gradlew assembleDebug
```

