# 📚 تطبيق إدارة الطلاب والمدفوعات

تطبيق Flutter متكامل لإدارة المجموعات الدراسية والطلاب وتتبع المدفوعات الشهرية بشكل احترافي وسهل الاستخدام.

## ✨ المميزات الرئيسية

### 🔐 نظام تسجيل الدخول الآمن
- تسجيل دخول برقم سري آمن
- إمكانية تغيير الرقم السري من الإعدادات
- دعم كامل للغة العربية

### 📚 إدارة المجموعات والطلاب
- إضافة وتعديل وحذف المجموعات الدراسية
- إضافة طلاب جدد مع تسلسل تلقائي للمسلسلات
- واجهة سهلة وسريعة للتنقل بين المجموعات

### 💰 تتبع المدفوعات
- جدول شهري تفاعلي للمدفوعات (أغسطس إلى يونيو)
- تسجيل المبالغ المستحقة والمدفوعة
- تمييز الشهور المسددة وغير المسددة بألوان واضحة
- تعديل سهل لبيانات المدفوعات

### 📊 تقارير وإحصائيات
- إجمالي المبالغ المحصلة لكل شهر
- عرض إجمالي التحصيل السنوي
- قائمة الطلاب المتأخرين
- تصفية النتائج حسب المجموعة أو الش��ر
- البحث عن الطلاب بالاسم

### 🔧 الإعدادات المتقدمة
- تغيير الرقم السري بسهولة
- نسخ احتياطية للبيانات
- استعادة النسخ الاحتياطية
- تبديل الوضع الليلي والوضع الفاتح
- معلومات عن التطبيق والإصدار

## 🛠️ التكنولوجيا المستخدمة

### Frontend
- **Flutter** - إطار عمل متعدد المنصات
- **Dart** - لغة البرمجة
- **Provider** - إدارة الحالة
- **Go Router** - التنقل بين الشاشات

### Backend
- **SQLite** - قاعدة بيانات محلية
- **Sqflite** - مكتبة Flutter للتفاعل مع SQLite

### المكتبات الإضافية
- `uuid` - توليد معرفات فريدة
- `intl` - دعم التدويل والعربية
- `excel` - تصدير إلى ملفات Excel
- `pdf` - تصدير إلى ملفات PDF
- `path_provider` - إدارة المسارات

## 📋 المتطلبات

## 🚀 البدء السريع

### 1. استنساخ المستودع
```bash
git clone https://github.com/eidgreer-ai/student-payment-admin.git
cd student-payment-admin
```

### 2. تثبيت المتطلبات
```bash
flutter pub get
```

### 3. تشغيل التطبيق
```bash
# على جهاز محاكي الاندرويد أو هاتف متصل
flutter run

# لتشغيل على الويب
flutter run -d chrome

# لتشغيل على سطح المكتب (Windows/Mac/Linux)
flutter run -d windows
```

### 4. تسجيل الدخول
- الرقم السري الافتراضي: **1234**
- يمكنك تغييره من قسم الإعدادات

## 📱 بناء ملف APK

### طريقة أولى: بناء محلي
```bash
# بناء APK بصيغة release
flutter build apk --release

# سيتم حفظ الملف في:
# build/app/outputs/flutter-apk/app-release.apk
```

### طريقة ثانية: بناء App Bundle (لـ Google Play)
```bash
flutter build appbundle --release

# سيتم حفظ الملف في:
# build/app/outputs/bundle/release/app-release.aab
```

## 🎯 دليل الاستخدام

### إضافة مجموعة جديدة
1. من الشاشة الرئيسية، اضغط على "المجموعات"
2. اضغط على زر الإضافة (+)
3. أدخل اسم المجموعة والوصف (اختياري)
4. اضغط "إضافة"

### إضافة طالب جديد
1. اختر المجموعة المطلوبة
2. اضغط على زر الإضافة (+)
3. أدخل اسم الطالب
4. سيتم تعيين مسلسل تلقائياً

### تسجيل المدفوعات
1. اختر الطالب المطلوب
2. اضغط على الخانة الخاصة بالشهر
3. أدخل المبلغ واختر الحالة
4. اضغط "حفظ"

### عرض التقارير
1. من الشاشة الرئيسية، اضغط على "الجرد والحسابات"
2. استخدم الفلاتر لتصفية النتائج
3. شاهد الإحصائيات والطلاب المتأخرين

## 🔐 الأمان والخصوصية
